> **本章导读**
>
> 森林火灾正在向哪里蔓延？一座城市十年间扩张了多少？洪水淹没了哪些农田？这些问题不可能只靠逐地点调查来及时回答。遥感提供了一种从远处、连续地观察地球的方式，也把“看见地表”发展成了可测量、可比较、可分析的信息。

## 学习目标

学完本章，你应当能够：

1. 用自己的语言解释遥感的广义与狭义概念；
2. 说出遥感技术系统的主要环节，并说明各环节解决什么问题；
3. 从平台、波段、工作方式和应用领域对遥感进行分类；
4. 概括遥感的优势、局限与主要发展趋势；
5. 解释遥感、GIS 与 GNSS 在资源环境问题中的分工与协同；
6. 为一个真实问题设计初步的遥感应用思路。

## 1. 什么是遥感

“遥感”由“遥”和“感”组成：**在不直接接触目标的情况下，从一定距离感知目标，并形成可解释的信息。** 日常生活中，人眼观察远处景物、相机拍摄影像，都具有“遥远感知”的意味；现代遥感则进一步依赖传感器、运载平台、数据传输和计算分析。

### 1.1 广义与狭义的遥感

| 理解层次 | 含义 | 典型例子 |
| --- | --- | --- |
| 广义遥感 | 一切不直接接触目标而获取其信息的方式 | 摄影、声呐、雷达、地震波探测 |
| 狭义遥感 | 传感器记录目标反射或发射的电磁辐射，据此识别地物性质及变化 | 卫星多光谱成像、航空摄影、合成孔径雷达 |

本课程主要讨论狭义遥感，即以电磁波为信息载体的对地观测技术。

> **核心定义**
>
> 遥感是利用安装在平台上的传感器，在不直接接触目标的条件下，记录目标反射、发射或散射的电磁辐射，经传输、处理和解释，认识目标性质、状态及其变化的科学与技术。

这一定义包含四个问题：

- **从哪里看？** 地面、飞机、无人机、卫星等平台；
- **用什么感知？** 相机、多光谱仪、热红外传感器、雷达等；
- **感知什么？** 地物反射、发射或散射的电磁能量；
- **得到什么？** 影像、光谱、温度、形变、分类图和变化信息。

### 1.2 遥感不等于遥测，也不等于遥控

- **遥感**关注从远处获取目标自身的特征信息，例如从影像判断植被覆盖状况。
- **遥测**关注远距离传输测量值，例如自动气象站把温度和气压传回中心。
- **遥控**关注从远处向设备发送指令，例如控制无人机调整航线。

同一个地球观测任务中三者可以同时出现，但它们解决的问题不同。

### 1.3 遥感为什么能够识别地物

太阳或传感器发出的电磁能量到达地表后，会发生反射、吸收、透射和散射；温度高于绝对零度的物体还会向外发射能量。不同地物的材料、结构、含水量、粗糙度和温度不同，对各波长能量的响应也不同。

这种随波长变化的响应规律称为**光谱特征**。例如，健康植被通常在可见光红波段吸收较强，在近红外波段反射显著增强；清洁深水体在近红外波段往往很暗。传感器记录这些差异，我们才能在影像中区分地物。

## 2. 遥感技术系统与信息链

遥感不是“卫星拍一张照片”这么简单，而是一条从能量到知识的信息链：

**信息源 → 大气传播 → 地物作用 → 传感器记录 → 数据传输 → 数据处理 → 信息提取 → 应用决策**

| 环节 | 核心问题 | 主要产出 |
| --- | --- | --- |
| 信息源 | 能量从哪里来？ | 太阳辐射或传感器主动发射的能量 |
| 大气传播 | 能量如何穿过大气？ | 受到吸收、散射后的有效信号 |
| 地物作用 | 地物如何改变能量？ | 反射、发射与后向散射特征 |
| 平台与传感器 | 在何时、何地、以何种尺度记录？ | 数字影像、光谱或测量数据 |
| 传输与接收 | 数据如何安全到达地面？ | 原始数据产品 |
| 预处理 | 如何消除几何、辐射和大气影响？ | 可定位、可比较的基础产品 |
| 信息提取 | 影像中有哪些地物和变化？ | 分类、参数反演、目标与变化信息 |
| 应用 | 信息如何回答现实问题？ | 专题图、统计结果、风险判断与决策依据 |

### 2.1 平台、传感器与目标

**平台**决定观测高度、覆盖范围、机动性和重复观测能力；**传感器**决定能记录哪些波段、细节和能量差异；**目标**及其环境决定最终信号。三者共同影响数据是否适合某个问题。

例如，监测区域洪水需要较大覆盖范围和及时重访；测绘一处滑坡则更强调空间细节和地形信息。不存在对所有任务都“最好”的遥感数据，只有与问题相匹配的数据。

### 2.2 从数据到信息需要处理

原始遥感数据并不天然等于可靠结论。常见处理包括：

- 辐射定标与大气校正，使不同时相的数值更可比较；
- 几何校正与正射校正，使像元对应正确的地理位置；
- 影像增强与波段组合，突出关心的地物差异；
- 分类、目标识别和参数反演，把像元转化为专题信息；
- 精度评价与不确定性分析，说明结果有多可信。

> **方法提醒**
>
> 遥感结论既来自传感器记录，也来自处理方法、辅助数据和解释者的知识。分析时必须保留数据来源、处理步骤和精度信息。

## 3. 遥感的主要特点

### 3.1 大范围、宏观和综合

卫星能够在较短时间内获得大范围、连续的地表信息，便于认识流域、城市群、生态区乃至全球尺度的空间格局。它特别适合交通不便、环境恶劣或难以逐点调查的地区。

### 3.2 重复观测与动态监测

卫星沿规律轨道重复经过同一区域，能够形成时间序列。比较多期数据可以发现城市扩张、湖泊涨落、作物生长、植被恢复和灾害演变。

“重访周期”不能脱离具体卫星来谈。Landsat 1—3 的重复周期为 18 天；自 Landsat 4 起采用的轨道系统为 16 天。现役 Landsat 8 与 Landsat 9 相位错开，两星合用可约每 8 天获得一次同一区域观测机会。

### 3.3 多波段、多尺度与信息丰富

传感器可记录人眼可见范围之外的紫外、红外和微波信息。不同波段强调不同性质，多种空间、时间、光谱和辐射分辨率的数据可以服务不同层次的问题。

### 3.4 客观记录与可比较

数字传感器按照统一规则记录能量，为跨地区、跨时期比较提供基础。规范的定标、校正和质量控制能够建立长期一致的数据记录。

### 3.5 优势并不意味着没有局限

遥感通常是对地物性质的**间接推断**。云和大气会遮挡或改变信号；混合像元会把多种地物压缩进一个数值；相似光谱可能对应不同地物，同一地物也会因季节、角度或湿度呈现不同响应。因此，高质量应用往往还需要地面调查、统计资料、GIS 数据和专业知识验证。

## 4. 遥感的主要分类

遥感可以从不同角度分类。同一套数据可以同时属于多个类别。

| 分类依据 | 主要类型 | 说明 |
| --- | --- | --- |
| 平台 | 地面、航空、航天 | 高度越高通常覆盖越广；低空平台通常更灵活、细节更丰富 |
| 电磁波段 | 紫外、可见光、红外、微波 | 不同波段对应不同地物响应和大气条件 |
| 能量来源 | 被动遥感、主动遥感 | 被动接收自然辐射；主动发射能量并接收返回信号 |
| 成像方式 | 成像、非成像 | 前者形成空间影像，后者侧重连续光谱或特定参数 |
| 应用领域 | 资源、环境、农业、林业、水文、海洋、气象、测绘等 | 按要解决的实际问题划分 |

### 4.1 被动遥感与主动遥感

**被动遥感**不主动照射地物，主要记录太阳光的反射或地物自身的热辐射。多光谱相机和热红外传感器是常见例子。

**主动遥感**由传感器发射能量，再测量目标返回的信号。雷达和激光雷达属于主动遥感。部分微波雷达能够穿透云层并昼夜工作，因此在洪水、海洋、极地和形变监测中非常重要。

### 4.2 常用波段范围

下列范围是便于入门的近似划分，不同学科和传感器的界限可能略有差异：

- 紫外：约 0.05—0.38 μm；
- 可见光：约 0.38—0.76 μm；
- 红外：约 0.76—1000 μm，可进一步分为近红外、短波红外与热红外；
- 微波：约 1 mm—1 m。

不要把“波段更多”简单等同于“数据更好”。波段位置、信噪比、空间分辨率、重访时间和任务需求需要综合权衡。

## 5. 遥感发展简史

遥感的发展与摄影、航空航天、电子学、计算机和地球科学密切相关。

| 时期 | 代表事件 | 能力变化 |
| --- | --- | --- |
| 19 世纪 | 摄影技术出现；气球航空摄影开始尝试 | 把瞬时观察变成可保存的影像 |
| 20 世纪上半叶 | 飞机与航空摄影快速发展 | 形成大范围、系统化测绘能力 |
| 1950 年代 | “remote sensing”一词在美国科研工作中得到使用 | 从航空摄影扩展为综合探测概念 |
| 1957 年 | 第一颗人造地球卫星进入轨道 | 开启航天观测时代 |
| 1960 年 | TIROS-1 气象卫星发射 | 展示卫星连续观测天气系统的价值 |
| 1972 年 | ERTS-1（后更名 Landsat 1）发射 | 开启系统性的陆地资源卫星观测 |
| 1980—1990 年代 | 多光谱、热红外、雷达与数字处理发展 | 遥感从影像判读走向定量分析 |
| 1999 年前后 | IKONOS 等商业高分辨率卫星出现 | 米级空间细节进入广泛应用 |
| 21 世纪 | 高分辨率、高光谱、星座、开放数据与云计算并行发展 | 观测更快、更细、更丰富，处理更自动化 |

### 5.1 从摄影到数字地球观测

早期遥感强调“看见地表”，成果多为照片和人工判读。数字传感器出现后，像元值可以参与计算、比较和建模；多光谱、热红外、微波和高光谱数据让人们能够估算植被、水分、温度、形变和大气成分。

### 5.2 中国对地观测能力

我国已形成包括气象、海洋、资源、环境减灾和高分专项在内的多类型对地观测体系。高分系列覆盖光学、雷达与高光谱等方向，服务自然资源调查、生态环境保护、灾害监测、农业估产和基础测绘等任务。

以高分五号为例，其高光谱观测能力面向大气和陆地环境监测；高分七号强调高精度立体测绘。这些任务说明，现代遥感已从“获得更清楚的照片”转向“获得更准确的地球参数”。

## 6. 遥感的发展趋势

### 6.1 更快：高重访与星座化

小卫星和星座通过多星协同提高重访频率，使近实时监测成为可能。未来评价系统能力时，应同时关注空间分辨率和时间分辨率，而不是只追求“看得更细”。

### 6.2 更丰富：多源、多模态与全谱段

光学、热红外、微波、激光雷达和高光谱数据各有优势。多源融合可以同时获得颜色、温度、结构、形变与成分信息，但也带来配准、尺度差异和误差传播问题。

### 6.3 更定量：从识别地物到反演参数

现代遥感不仅回答“这是什么”，还尝试回答“有多少”和“变化多快”，例如估算叶面积指数、地表温度、土壤湿度、生物量和大气污染物浓度。定量反演依赖物理模型、训练样本与地面验证。

### 6.4 更智能：云计算与人工智能

海量时序数据推动自动预处理、深度学习识别和云端分析。人工智能能提高效率，却不能自动消除数据偏差。训练样本是否代表真实环境、模型能否迁移、结果如何解释，仍然需要专业判断。

### 6.5 更开放：数据共享与社会化应用

长期开放的数据档案和在线计算平台降低了使用门槛。遥感正在从少数专业机构的工具，转变为科研、治理、企业和公众都能使用的空间信息基础设施。

## 7. 遥感、GIS 与 GNSS：3S 如何协同

“3S”通常指遥感（RS）、地理信息系统（GIS）和全球卫星导航系统（GNSS；传统教材常写 GPS）。三者不是彼此替代，而是完成不同任务。

| 技术 | 核心能力 | 在项目中的典型角色 |
| --- | --- | --- |
| RS 遥感 | 大范围、重复地获取地表信息 | 发现地物、估算参数、监测变化 |
| GIS 地理信息系统 | 管理、分析和表达空间数据 | 叠加多源资料、空间分析、制图表达 |
| GNSS 全球卫星导航系统 | 获取位置、时间与导航信息 | 野外定位、样点采集、精度验证 |

以洪水评估为例：遥感提取淹没范围，GNSS 支持现场核查，GIS 叠加人口、道路和土地利用数据，最终得到受影响区域和应急路线。完整的资源环境信息技术链条常常是：

**GNSS 定位调查 + RS 动态获取 + GIS 综合分析与表达**

## 8. 遥感的资源环境应用

### 8.1 资源调查与监测

- 土地利用与土地覆盖调查；
- 作物类型识别、长势监测与产量估算；
- 森林覆盖、病虫害与生物量监测；
- 矿产与地质构造线索识别；
- 地表水体、积雪、冰川与海洋要素监测。

### 8.2 环境与灾害

- 大气污染、热环境和水环境监测；
- 洪水、森林火灾、干旱和地震灾情评估；
- 滑坡、地面沉降与冰川运动监测；
- 生态退化、荒漠化和湿地变化评价。

### 8.3 规划、测绘与全球变化

- 城市扩张、交通设施和规划实施监测；
- 地形测绘、正射影像和三维模型生产；
- 考古遗迹与历史景观调查；
- 全球植被、海冰、碳循环和气候变化研究。

### 8.4 从问题出发选择数据

| 应用问题 | 首先关注的观测能力 | 可能的辅助资料 |
| --- | --- | --- |
| 洪水快速制图 | 高重访、全天候观测、较大覆盖 | 地形、河网、居民地 |
| 城市扩张监测 | 长时间序列、稳定分类能力 | 规划边界、人口与道路 |
| 作物长势监测 | 多时相、红光与近红外波段 | 物候、气象、田块边界 |
| 地表温度研究 | 热红外与可靠的大气校正 | 地表覆盖、气象观测 |
| 滑坡形变监测 | 雷达干涉或高精度重复测量 | 地质、降雨、现场调查 |

一个好的遥感应用设计通常依次回答：**问题是什么？需要观察什么变量？多大的范围与细节？多久观察一次？如何验证？**

## 本章小结

1. 遥感是在不直接接触目标的条件下，通过记录电磁辐射来认识目标的科学与技术。
2. 完整遥感系统包括能量传播、平台与传感器、数据传输、预处理、信息提取和应用。
3. 遥感具有大范围、重复、多波段和可比较等优势，但结论是间接推断，必须关注误差与验证。
4. 平台、波段、主动或被动、成像方式和应用领域构成了不同分类视角。
5. 遥感正走向高重访、多源融合、定量化、智能化和开放化。
6. RS、GIS 与 GNSS 分别侧重获取、分析表达和定位，协同构成资源环境信息技术的重要基础。

## 自测与思考

1. 为什么说遥感结果通常是对地物性质的间接推断？
2. 阴雨天气持续时，为什么微波雷达可能比可见光影像更适合洪水监测？
3. “空间分辨率越高，数据越好”这句话有什么问题？
